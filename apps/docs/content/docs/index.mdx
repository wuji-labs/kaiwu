Kaiwu 运行在你掌控的计算机上，支持 Claude Code、Codex、OpenCode、Cursor、Gemini 等十余种编程智能体。你可以通过手机、浏览器或另一台设备，实时查看、引导、审批并回复智能体。所有工作均在你自己的硬件设备和代码仓库中执行，使用的是智能体自身的凭据。

所有会话均通过端到端加密进行同步。在 Kaiwu 云端服务以及采用默认配置的自托管服务器上，服务端仅保存密文和路由元数据，无法读取你的对话内容。自托管运维人员也可以选择明文存储策略——[安全](/security)详细说明了该策略带来的具体变化。

**运维与安全**
