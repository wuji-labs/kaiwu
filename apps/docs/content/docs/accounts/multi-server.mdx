Kaiwu 支持同时使用多个服务器（例如 Kaiwu Cloud + 个人自托管 + 公司自托管）。

## 核心模型

- **服务器配置文件**（server profile）即已保存的 API 或 Web 应用目标地址。
- 身份认证**限定在服务器级别**。登录 `server A` 并不会自动登录 `server B`。
- 守护进程与运行时状态同样限定在服务器级别，因此一台设备可以安全运行多个守护进程实例。

即便在两个服务器上使用相同的身份提供商（例如 GitHub），它们依然是彼此独立的服务器账户。

## App 与 Web 界面

### 添加与切换服务器

- 打开**服务器**设置，可添加、选择、重命名或删除已保存的服务器。
- 在 Web 端，服务器选择可针对单标签页生效，也可设为当前设备的默认值。
- 若连接链接或通知链接指向另一个**已保存**的服务器，Kaiwu 会在继续操作前自动切换到该服务器。
- 若通知指向一个**尚未保存**的服务器，Kaiwu 不会盲目替换你现有的服务器配置。

#### 收到未保存服务器的通知

Kaiwu 会根据当前设备的已有配置采取不同的处理方式：

- **尚无已保存的服务器**：Kaiwu 会自动初始化该服务器，确保通知链接仍能正常打开目标会话
- **已存在一个或多个已保存的服务器**：Kaiwu 会打开**服务器设置**并自动填入传入的 URL，提示你明确添加该服务器

选择**添加并使用**（Add & Use）后，Kaiwu 将自动跳转至挂起的会话或请求。

### 服务器配置链接

安装程序和配置命令可输出一键配置链接：

- `happier://server?url=<ENCODED_SERVER_URL>`
- `<WEBAPP_URL>/?server=<ENCODED_SERVER_URL>`（推荐）
- `<WEBAPP_URL>/server?url=<ENCODED_SERVER_URL>&auto=1`（旧版）

这些链接会自动预填服务器设置，省去手动粘贴 URL 的麻烦。

## CLI 服务器配置文件

### 持久化配置文件

使用服务器配置文件管理命令：

```bash
happier server list
happier server current
happier server add --name company --server-url https://api.company.example --webapp-url https://app.company.example --use
happier server use company
happier server remove company
happier server test company
```

### 单次命令指定服务器（不切换默认值）

仅对单条命令指定目标服务器：

```bash
happier --server company auth login
happier --server personal daemon status
```

也可以在单次调用时直接传入明确的 URL：

```bash
happier --server-url https://api.company.example --webapp-url https://app.company.example auth login
```

## 单设备运行多个守护进程

为各个服务器配置文件分别安装/启动独立的守护进程服务：

```bash
happier --server personal daemon service install
happier --server company daemon service install
```

检查状态：

```bash
happier daemon status --all
happier --server personal daemon service status
happier --server company daemon service status
```

## 推荐流程

1. 添加或选择目标服务器。
2. 在该服务器上登录（通过 App 或 Web 端）。若已在其他设备上使用 Kaiwu，请使用同一账户登录。
3. 为该服务器连接终端或守护进程。

完整端到端操作指南请参阅 [新手引导](/getting-started/onboarding) 与 [Proxmox 部署指南](/self-hosting/proxmox)。

## 常见问题与避坑指南

### 未登录状态下打开了终端连接链接，会发生什么？

Kaiwu 会暂存该终端连接请求，引导你完成登录或注册流程，随后自动返回终端授权确认界面。

### 为什么在两个服务器上使用了同一个提供商登录，看到的数据却不同？

账户按服务器独立隔离。虽然身份提供商相同，但各个服务器的账户和会话状态彼此独立。

### 切换服务器后之前的会话不见了？

这是正常现象，之前的会话归属于另一个服务器。切回对应的服务器配置文件即可重新看到这些会话。

### 点击通知后，Kaiwu 没有直接打开会话，而是跳转到了“服务器设置”，为什么？

这通常是因为设备上已有其他保存的服务器，而该通知来自一个尚未保存的服务器 URL。

Kaiwu 有意这样设计，避免在后台静默添加或信任不受控的新服务器。在已自动预填的表单中确认添加该服务器后，Kaiwu 便会自动跳转至目标会话。
