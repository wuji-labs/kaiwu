---
title: 参与者路由与实时运行消息
description: 在同一个会话 UI 中向主导者、Claude 团队成员或正在执行的运行发送消息。
---
Kaiwu 支持在会话内进行**参与者路由**。

这意味着同一个会话输入框可以指定发送给：

- 常规 **Lead** Agent，
- 指定的 **Claude 队员**，
- Claude **广播**目标，或
- **正在执行的运行实例**。

这也是围绕 Claude 团队、子 Agent 以及执行运行所构建路由功能的用户端交互模型。

## 可以在哪里路由消息

你可以从以下位置路由发送消息：

- **主会话输入框**，
- 聚焦的**子 Agent / 队员 / 运行详情**视图，
- 受支持的工具支持型子 Agent 会话记录详情视图。

若当前界面没有其他备选接收方，输入框的表现与普通会话输入框完全一致。

## 接收方标签

当存在备选接收方时，输入框会显示一个 **Send to** 标签。

根据具体会话的不同，该标签可列出：

- **Lead**
- 一个或多个 **Claude 队员**
- **Broadcast**
- 一个或多个**正在执行的运行实例**

Kaiwu 会在该界面保持打开期间**记住当前界面的选择**。若离开并重新打开该界面，选项将重置为该界面的默认状态。

## 依视图感知的自动选择

若打开某个队员或运行实例的聚焦会话记录，Kaiwu 可为输入框自动选中对应的接收方。

这一行为仅在满足以下条件时生效：

- 聚焦视图明确对应单个接收方，且
- 你**尚未**在该界面手动切换过其他接收方。

例如：

- 打开 Claude 队员的会话记录，可自动选中该队员；
- 打开正在执行的运行实例会话记录，可自动选中该运行；
- 一旦手动切换了接收方，在当前界面停留期间，始终以手动选择为准。

## 发送后的处理逻辑

### Lead

发送给 **Lead** 等同于发送一条常规会话消息：

- 显示为标准用户消息，
- 附件功能正常可用，
- 审查批注草稿正常可用。

### Claude 队员或广播

发送给 Claude 队员或广播目标会生成一条**路由参与者消息**。

用户可见的行为表现：

- Kaiwu 会在会话记录中保留输入的原始内容，
- 会话记录会展示结构化卡片，例如 **To: alpha** 或 **To: Broadcast: qa-team**，
- 该卡片在视觉样式上与普通用户气泡明显区分。

与用户相关的实现细节：

- Kaiwu 会重写发送给 Claude 的后端提示词，
- 但界面**不会**展示这些专属于 Claude 的内部重写内容，
- 你只能看到自己实际键入的消息。

### 正在执行的运行实例

发送给正在执行的运行实例时，消息会直接投递至该运行，而非主会话。

当审查、委托任务或其他运行实例已经在执行，而你希望微调其行为且无需重新开始时，此功能非常有用。

## 运行实例投递模式

当选中的接收方是运行实例时，Kaiwu 会显示一个 **Delivery** 标签。

应用当前对外提供两种模式：

### Steer

此为默认模式。

行为表现：

- 若后端支持实时引导，Kaiwu 会立即引导当前的交互轮次，
- 否则 Kaiwu 会中止当前轮次，并将你的消息作为下一轮次发送，
- 运行本身仍会继续；Kaiwu **不会**因为无法实时引导而直接终止整个运行实例。

适用于希望尽可能减少干扰、平滑跟进的场景。

### Interrupt

行为表现：

- Kaiwu 始终会中止当前轮次，
- 随后立即将你的新指令作为新轮次发送。

适用于当前轮次明显偏离预期方向、需要立即予以替换的场景。

## 运行实例何时可接收消息

运行实例仅在其实际处于可发送状态时，才会作为接收方列出。

实际表现为：

- 正在执行的长生命周期运行，只要保持活跃即可持续供选，
- 有范围限制的短运行，仅在其活跃轮次仍在执行时可选，
- 一旦运行完成、停止或转为不可发送状态，就会从接收方列表中移除。

正因如此，有时某个运行泛义上仍显示为**运行中**，却已无法提供发送控件：Kaiwu 遵循的是运行时真正的可发送性契约，而不是依靠可能过期的会话记录状态进行猜测。

## 路由消息在会话记录中的呈现方式

路由参与者消息会渲染为结构化消息卡片。

卡片明确展示：

- 消息发送给**谁**，
- 你键入的**原始内容**。

卡片特意隐去了：

- 特定后端的提示词重写内容，
- Claude 特有的内部路由指令。

## 在何处跟踪接收方的工作进展

你可以通过以下任一位置查看接收方的工作情况：

- **Agents** 面板 / Agents 侧边栏，
- 会话时间线中的原始**工具或会话记录条目**。

对于受支持的子 Agent 和运行实例，这两种路径都会导向相同的底层会话记录与详情流。

## 当前限制

当前，发送至 Claude 队员的路由消息**不**支持：

- 附件，
- 审查批注草稿。

如果需要使用这些功能，请改用常规的 **Lead** 消息发送。

运行实例路由也仅限于暴露了真实控制链路的接收方。部分提供商创建的侧链属于只读监控类型，因此仅作为可供查看的会话记录出现，无法作为接收方接收消息。
