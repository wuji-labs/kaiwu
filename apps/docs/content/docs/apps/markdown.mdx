Agent 习惯使用 Markdown 编写内容，因此你在 Kaiwu 中阅读的大多数文本都经过了渲染，而非直接展示原始内容。这里有两点值得了解：图表渲染支持，以及自行编辑 Markdown 文件时的处理机制。

## Mermaid 图表

会话记录中的 Mermaid 图表会直接渲染成图形，包括 iOS 和 Android 在内的全端客户端均已支持。

Mermaid 运行时**随 App 一同打包内置**，而非从 CDN 动态拉取。在实际使用中，这保障了两种关键场景的体验：即使设备处于受限网络中，图表仍可正常渲染；同时，图表渲染绝不会向任何第三方泄露你正在查看的内容。图表源码在渲染前均经过安全过滤，原生渲染器也严格限制了其 Web 视图的权限，杜绝与 App 的网络、消息及导航环境产生交互。

## Markdown 富文本编辑器

在 Kaiwu 编辑器中打开 Markdown 文件时，你可以像编辑排版文本一样直接修改内容，无需编写原始语法——标题、强调、行内代码、任务列表、引用块、代码块、分割线与链接一应俱全，且支持类似 Notion 的斜杠（/）命令快捷插入。排版预览会随输入实时更新。

<Callout type="info">
  富文本编辑器目前为实验性功能，默认处于关闭状态。如需启用，请前往 **设置 → 功能 → Markdown 富文本编辑器**；需要注意的是，只有开启该界面顶部的实验功能总开关后，相关实验性选项才会显示。详情请参阅 [功能标志](/extras/feature-flags) 中的 `files.markdownRichEditor` 说明。
</Callout>

为避免文件内容受损，遇到以下情况时它会自动回退到原始 Markdown：

- 文档双向转换可能丢失内容；
- 文件体积过大；
- 当前客户端未包含该编辑器资源包。

在原始语法与富文本视图之间切换不会丢失已写内容；编辑器会在切换的临界点同步刷写待保存的更改，避免两种视图内容出现分歧。

表格、数学公式、Mermaid 图表与图片目前暂不支持在富文本视图中直接编辑。包含这些元素的文件依然可以正常打开，但需在原始 Markdown 模式下编辑。
