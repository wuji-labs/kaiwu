桌面端应用是配置 Kaiwu 与管理设备的核心控制台。

你可以借助它来协调以下四项内容：

1. **选择中继**
2. **登录账户**
3. **配置守护进程与设备**
4. **为自托管中继配置可选的安全访问**

## 推荐操作流程

### 1. 首先选择中继

打开桌面端应用。在注册或登录账户之前，先选定要使用的中继。

这样可以避免常见的配置脱节问题：

- 应用登录了一个中继
- CLI 或守护进程却指向另一个中继
- 账户明明有效，后续的终端或守护进程配置却看似“出现故障”

### 2. 在该中继上登录

选定中继后，在该中继上登录或注册账户。

应用会将账户状态隔离在所选中继的作用域内，后续切换到其他中继也不会覆盖原先的中继配置。

### 3. 配置设备

在桌面端应用中，你可以选择：

- **配置此电脑**：针对当前生效的中继配置本地守护进程与后台服务
- **通过 SSH 添加设备**：直接在桌面端应用中配置远程设备

上述流程的主要入口是应用内的 `/setup` 页面。

若守护进程运行在你的笔记本或台式机上，推荐使用本地流程；若守护进程运行在远程服务器上，而你仍希望通过笔记本进行管理，推荐使用 SSH 流程。

## 控制台支持的管理功能

### 中继设置

在“中继设置”页面中，你可以：

- 添加并保存多个中继配置文件
- 切换当前生效的中继
- 检测守护进程是否连接到了其他中继
- 直接在应用中修复中继漂移，无需手动重新配置

### 设备

在“设备”页面中，你可以：

- 配置当前电脑
- 通过 SSH 配置远程设备
- 为刚刚就绪的目标设备继续配置提供商

### 本地自托管中继运行时

如果你在本地运行自托管中继，应用还可以管理本地中继运行时：

- 查看运行状态
- 安装或更新运行时
- 启动或停止运行时
- 显示本地中继 URL

### 供其他设备使用的私有访问

针对本地或自托管中继，应用可引导你完成安全私有访问的配置，方便手机或其他电脑访问该中继，且无需将其暴露在公网中。

目前该功能以桌面端应用内的本地安全访问任务形式提供。

## 中继漂移

中继漂移是指应用正在使用某一个中继，而守护进程或后台服务却配置在另一个中继上。

桌面端应用会明确提示此状态，并提供一键修复操作。

这一功能非常关键，因为许多“为什么连不上守护进程、终端或设备”的问题，本质上都是中继不一致导致的，并非鉴权失败。

## 常见架构方案

### 托管中继 + 本地守护进程

- 在应用中选择 Kaiwu Cloud
- 登录账户
- 使用**配置此电脑**

### 自托管中继 + 本地守护进程

- 在应用中添加或选择你的自托管中继
- 在该中继上登录
- 使用**配置此电脑**
- （可选）为手机及其他设备开启私有访问

### 自托管中继 + 远程守护进程

- 在应用中添加或选择你的自托管中继
- 在该中继上登录
- 使用**通过 SSH 添加设备**
- 为添加成功的设备继续配置提供商

### 混合架构（远程中继 + 远程守护进程 + 笔记本控制台）

- 笔记本保留桌面端应用作为控制面板
- 在一台设备上运行中继
- 在另一台设备上运行守护进程与智能体
- 通过桌面端应用统一管理两者

## CLI 备用方式

CLI 依然提供底层命令（`server`、`auth`、`daemon` 及相关子命令），但我们推荐的用户流程是：

- 在应用中选定中继
- 在该中继上登录
- 由桌面端应用引导完成设备配置

这种方式能让中继、账户和设备的状态清晰可见，有效避免配置不一致。
