Kaiwu 拥有 33 个键盘命令，全部支持重新绑定。若操作系统的快捷键已被占用，Web 端与原生客户端的默认键位会有所不同。

<Callout type="warn">
  两项功能**默认处于关闭状态**：下文中的快捷键生效前，须先在**设置 → 快捷键**中开启快捷键注册表与命令面板。
</Callout>

`Mod` 在 macOS 和 iOS 上对应 Command 键，在其他平台对应 Control 键。若某项绑定字面直接写为 `Ctrl`，则在包括 macOS 在内的所有平台上均指 Control 键——此处系有意设计，用于遵循特定平台惯例，而非泛指“修饰键”。

## 命令面板

无需记忆快捷键即可执行各项操作的最快捷径。它将内置命令、自定义提示词以及 Kaiwu 操作汇集在同一个列表中供检索调用。

`Alt+K`（Web 端）· `Mod+K`（其他客户端）

## 快捷键

### 会话切换

| 操作 | 默认值 |
| --- | --- |
| 新建会话 | `Alt+N`（Web 端）· `Mod+Shift+N`（其他客户端） |
| 下一个最近使用的会话 | `Alt+PageDown`（Web 端）· `Ctrl+Tab`（其他客户端） |
| 上一个最近使用的会话 | `Alt+PageUp`（Web 端）· `Ctrl+Shift+Tab`（其他客户端） |
| 列表中的下一个会话 | `Alt+ArrowDown` |
| 列表中的上一个会话 | `Alt+ArrowUp` |

### 会话列表

| 操作 | 默认值 |
| --- | --- |
| 上移当前聚焦的会话 | `Alt+Shift+ArrowUp` |
| 下移当前聚焦的会话 | `Alt+Shift+ArrowDown` |
| 移动到文件夹 | `Alt+Shift+F` |
| 移出至工作区根目录 | `Alt+Shift+R` |
| 选中或取消选中当前聚焦行 | `Space`（Web 端） |
| 向上扩展选中范围 | `Shift+ArrowUp`（Web 端） |
| 向下扩展选中范围 | `Shift+ArrowDown`（Web 端） |
| 全选会话 | `Mod+A`（Web 端） |
| 取消选中 | `Escape`（Web 端） |

### 编写与发送

| 操作 | 默认值 |
| --- | --- |
| 跳转至输入框 | `Mod+I` |
| 立即发送 | `Mod+Enter` |
| 加入队列（不展开输入框） | `Mod+Shift+Enter` |
| 终止当前轮次 | `Mod+.`（Web 端）· `Shift+Escape`（其他客户端） |
| 切换会话模式 | `Alt+Shift+M` |
| 切换权限模式 | _默认未绑定_ |

### 查看会话记录

| 操作 | 默认值 |
| --- | --- |
| 下一条消息 | _默认未绑定_ |
| 上一条消息 | _默认未绑定_ |
| 跳至顶部 | `Home` |
| 跳至实时末尾 | `End` |
| 向上翻页 | `PageUp` |
| 向下翻页 | `PageDown` |
| 全选消息 | `Alt+Shift+A` |
| 复制所选消息 | `Alt+Shift+C` |
| 将所选内容发送至其他会话 | `Alt+Shift+S` |
| 取消选择 | `Escape` |

### 其他操作

| 操作 | 默认值 |
| --- | --- |
| 打开命令面板 | `Alt+K`（Web 端）· `Mod+K`（其他客户端） |
| 在应用中显示此列表 | `?` |
| 打开设置 | _默认未绑定_ |

快捷键会遵循当前的焦点状态。在输入框中键入内容时，绝大多数快捷键不会响应；因此发送操作拥有独立且可安全用于编辑场景的按键绑定，无需先移出输入框焦点。

## 修改快捷键

前往**设置 → 快捷键**，可以查看每个命令及其当前绑定的按键并进行自定义设置。设置快捷键时系统会自动检测冲突。配置按设备单独存储，不会在多端间同步，因此笔记本与台式机可以保持不同的键位方案。
