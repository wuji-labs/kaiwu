无论身在何处，Kaiwu 始终对应同一个账号与同一批会话。不同的只是你接入会话的前端界面，以及该界面能访问到的设备范围。

## Kaiwu 的运行环境

- [应用](/apps/app) — 覆盖桌面端、Web 端与移动端，也是你的主要日常使用环境。
- [桌面端控制面板](/apps/control-panel) — 负责处理依赖物理设备任务的桌面应用：中继、守护进程及安全访问配置。
- [Windows](/apps/windows) — 仅适用于该平台的专属行为与问题排查。
- [移动端自构建版本](/apps/custom-mobile-build) — 无需通过应用商店，自行构建面向自托管服务器的移动端应用。

## 终端环境

- [CLI](/apps/cli) — 安装、登录以及选择连接的服务器。
- [CLI 会话](/apps/cli-sessions) — 创建、列出、发送、恢复和接入会话，全部支持脚本化操作。
- [守护进程](/apps/daemon) — 无需打开终端窗口，持续保持远程控制可用。

## 界面功能

- [附件与图片预览](/apps/attachments)
- [Markdown 与图表](/apps/markdown) — 会话记录的渲染效果，以及 Markdown 文件编辑器。
- [主题](/apps/themes) — 内置主题、自定义主题以及多设备间的主题迁移。
- [快捷键](/apps/keyboard-shortcuts) — 所有支持重新绑定的快捷键及命令面板。

## 跨界面的通用能力

无论使用哪种界面，底层的控制平面都完全一致：统一的账号与服务器选择，Agent 或用户可调用的同一套操作目录，针对各界面的独立操作设置，以及操作受控时完全相同的审批流程。

正因如此，笔记本电脑上的会话发起的审批，可以直接在手机上处理；语音指令和外部 MCP 宿主，也能驱动与应用完全相同的操作。
