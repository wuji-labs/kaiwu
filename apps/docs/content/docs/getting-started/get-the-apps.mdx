Kaiwu 会在你所控制的计算机上运行编程智能体，并支持你从其他位置远程操控它们。因此，你需要准备两样东西：负责执行任务的设备上的 CLI，以及用于进行操控的客户端。

建议先从客户端开始。没有客户端，你将无法完成 CLI 的登录流程——终端会输出一段验证码，需要你在已登录的浏览器或手机上进行确认。

iOS 客户端提供未签名安装包（需自签或 TestFlight）；同时推荐使用 Web 应用方式：在 iPhone / iPad 上使用 Safari 打开 [kaiwu.chengqiyun.com](https://kaiwu.chengqiyun.com)，点击底部「分享」按钮选择「添加到主屏幕」，即可获得如同原生应用的完整体验。

## 浏览器端

[kaiwu.chengqiyun.com](https://kaiwu.chengqiyun.com) 是功能完备的全功能客户端——无需安装，也是体验 Kaiwu 是否契合你需求的最快方式。它同时也是完成 CLI 登录最便捷的途径，因为在当前正在配置的设备上，你的浏览器很可能已经处于登录状态。

## 桌面端

当前桌面端发布渠道为「安装 CLI + 浏览器 / 添加到主屏幕应用」。在桌面设备上安装运行 CLI，并搭配浏览器即可驱动智能体：

在 macOS / Linux 上安装 CLI：

```bash
curl -fsSL https://kaiwu.chengqiyun.com/install | bash
```

在 Windows 上使用 PowerShell 安装 CLI：

```powershell
irm https://kaiwu.chengqiyun.com/install.ps1 | iex
```

更多版本及发布信息可在 [Releases](https://github.com/wuji-labs/kaiwu/releases) 页面查看。

## 运行智能体的设备

这是实际承载任务执行的部分，它是一个 CLI（命令行工具），而非图形应用：

```bash
curl -fsSL https://kaiwu.chengqiyun.com/install | bash
```

在 Windows 上使用 PowerShell 安装：

```powershell
irm https://kaiwu.chengqiyun.com/install.ps1 | iex
```

安装程序会在解包前验证每个版本的签名。关于其他安装方式、发布通道以及安装后提示命令未找到时的排查方法，请参阅 [CLI](/apps/cli)。
