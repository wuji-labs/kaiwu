读完本文，你就能在自己的电脑上运行编程 Agent，并随时通过手机、浏览器或其他设备查看运行状态、调整方向、审批操作或直接回复。

Kaiwu 不会替代你现有的编程 Agent，而是直接驱动你已在使用的工具——无论是 Claude Code、Codex、OpenCode、Gemini、Cursor、Copilot、Qwen Code、Kimi、Kiro、Kilo、Auggie、Pi 还是 Grok——并为其提供一套远程控制能力。

## 准备工作

只需准备四项内容。后三项很快就能搞定，第一项往往最容易被忽视。

1. **一台保持开机唤醒的电脑。** Kaiwu 负责建立你*与*自身设备的连接，而不会在云端运行 Agent。笔记本电脑一旦休眠，会话就会中断。如果你希望合上电脑盖后任务仍能继续运行，请使用台式机、VPS 或常开供电的主机。
2. **已在该电脑上安装并完成登录的编程 Agent CLI。** Kaiwu 本身不内置任何 Agent，只会自动检测现有的工具。如果 `claude`（或 `codex`、`opencode`）目前无法在你的终端中直接运行，那它同样无法通过 Kaiwu 运行。
3. **一个 Kaiwu 账号**，请在 App 或 Web 客户端中注册，而非通过终端创建。CLI 的登录实际上是一个*审批*授权步骤，需要向已登录的客户端发起确认。
4. **大约十分钟时间**，以及一部手机或另一个用于审批授权的浏览器标签页。

你**无需**自备服务器，无需安装 Node.js 或 npm，也无需自行构建 App。

## 1. 获取客户端

安装 App，或者直接打开 [kaiwu.chengqiyun.com](https://kaiwu.chengqiyun.com/)——Web 客户端包含完整功能，无需安装。在页面中创建账号即可。

访问[获取应用](/getting-started/get-the-apps)，下载适用于 iPhone、Android、桌面端或浏览器的客户端。

<Callout type="warn">
  你的账号是一串保存在本地设备上的密钥，而非存储在服务器上的密码。登录成功后，请前往**设置 → 账号**进行备份。若在没有备份的情况下丢失了所有已登录设备，账号将无法找回。
</Callout>

## 2. 在执行任务的设备上安装 CLI

<Tabs items={['macOS / Linux', 'Windows']}>
<Tab value="macOS / Linux">
```bash
curl -fsSL https://kaiwu.chengqiyun.com/install | bash
```
</Tab>
<Tab value="Windows">
```powershell
iwr https://kaiwu.chengqiyun.com/install.ps1 -useb | iex
```
</Tab>
</Tabs>

安装程序会验证版本签名，解压至 `~/.happier`，并提示是否配置开机自启，以便在未打开终端时设备依然保持可连接状态。除非有特殊需求，建议选择同意。若为全新交互式安装，接下来会自动进入下文的配置流程。

安装程序会将 `~/.local/bin` 添加到你的 Shell 配置文件中，但当前已打开的 Shell 尚未重新加载该配置。进行下一步前，请打开新的终端窗口，或重新 source 配置文件。

## 3. 将设备连接至你的账号

如果是无人值守安装、跳过了引导设置，或者未完成登录，可以通过以下命令继续：

```bash
happier setup
```

配置流程会询问安装程序自身无法确定的一个问题——中继所在的地址。随后它会将这台电脑指向该中继，并引导你完成登录。你的账号保存在所选的中继上，因此该步骤必须在登录之前确认，而非事后设置。

如果你已知晓中继地址，可以直接跳过此提问：

```bash
happier setup --cloud                 # Kaiwu Cloud
happier setup --relay https://…       # a relay you already run
happier setup --this-computer         # install a relay here too
```

若需要重新登录，Kaiwu 会输出一个 URL；在中继可被其他设备访问的情况下，还会生成一个二维码。使用 App 扫码，或在已登录的浏览器中打开该 URL 并批准授权即可。仅监听本地环回地址的中继（`localhost` 或 `127.0.0.1`）无法从手机访问，因此重新认证步骤需要改在同一台电脑的浏览器中完成。如果已保存的登录凭据依然有效，仅仅缺少设备注册信息，配置流程会自动修复该注册状态，无需打开浏览器，也不会要求重新登录。

审批通过后，终端会自动继续执行后续流程。如果请求超时，当前请求将失效；请重新运行 `happier setup` 或 `happier auth login` 发起新请求并完成审批。

若所选的中继未响应，配置程序将无法验证已保存的登录凭据和设备注册状态。此时它会保留所选的中继地址与已保存的凭据，并提供重试选项或允许你显式切换到其他中继。中继宕机不会悄悄将这台电脑切换到 Kaiwu Cloud，也不会为你创建新账号。

配置流程还会检查系统是否已安装编程 Agent。若未安装，程序会给出提示——这不会阻止你继续操作，但很多人往往跳过此步，直到最后才遇到问题。

## 4. 开启你的第一个会话

```bash
happier
```

这将使用默认 Agent（Claude Code）启动一个会话。若要使用其他 Agent，直接指定其名称即可：`happier codex`、`happier opencode`、`happier cursor`。会话会在一两秒内显示在客户端中，之后你便可以在客户端中对其进行操控。

## 5. 确认一切正常运行

```bash
happier status
```

该命令会读取你的账号信息、中继注册状态、开机自启配置以及 CLI 通道，不会修改任何配置。后续如果遇到任何异常，应首先运行该命令进行排查——详见[检查配置](/getting-started/check-your-setup)。

## 常见问题与故障排查

**`happier: command not found`**——安装程序修改了你的 Shell 配置文件，但无法直接更改当前已打开的 Shell 环境。请打开一个新终端。如果你使用的是 fish，需要手动将 `~/.local/bin` 添加到 `fish_user_paths` 中；安装程序写入的是 `~/.profile`，fish 不会自动读取该文件。

**`Claude CLI (claude) is not available from any configured source`**——尚未满足准备工作中的第 2 项要求就已推进到最后一步。请先安装该 Agent（`curl -fsSL https://claude.ai/install.sh | bash`），完成登录并确认 `claude` 能够独立正常运行，然后再重新执行 `happier`。或者，直接使用你已安装的其他 Agent 来启动会话。

**设备始终未在 App 中显示**——账号登录与设备注册是两项独立的操作，设备注册通常在后台服务启动或会话开始时进行。运行 `happier status` 进行检查；如果提示设备未注册，运行 `happier doctor repair` 即可修复。
