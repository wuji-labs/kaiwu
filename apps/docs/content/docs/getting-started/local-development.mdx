## 首选方案：`hstack`（推荐）

在当前 monorepo 中开发 Kaiwu 时，官方推荐的工作流是通过 `hstack` 运行所有组件。这种方式能够按栈严格隔离端口、身份认证、数据库、缓存及运行时状态。

推荐阅读：

- [环境搭建](/hstack/setup)
- [开发工作流](/hstack/development)
- [快速入门](/hstack/quickstarts)

### 首次配置

```bash
hstack setup-from-source --profile=dev
```

### 运行开发栈（绑定至标准 `dev/` 检出）

```bash
hstack stack new dev
hstack stack wt dev -- use dev
```

交互式开发（首选）：

```bash
hstack tui stack dev dev
# mobile dev-client + QR:
hstack tui stack dev dev --mobile
```

若无法使用 TUI（例如在非交互式终端或 CI 环境中），请运行：

```bash
hstack stack dev dev
```

## 传统 / 手动方式（未按栈隔离）

如果不使用 `hstack`，可以使用下列命令。但需要注意，这些命令**未按栈进行作用域隔离**（会与你的设备共用端口、身份认证和缓存，较难并行运行）。

```bash
yarn install
```

随后启动服务器：

- 完整版：
```bash
yarn --cwd apps/server dev
```

- 轻量版：
```bash
yarn --cwd apps/server dev:light
```

## App（Web UI）

App 支持在本地以 Expo Web 形式运行：

```bash
yarn --cwd apps/ui web
```

## 官方网站

```bash
yarn --cwd apps/website dev
```
