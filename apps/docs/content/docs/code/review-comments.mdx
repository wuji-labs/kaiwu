---
title: 评审批注
description: 在文件和差异对比中针对特定行添加评审说明，然后将选中的批注发送给智能体。
---
借助评审批注，你可以在工作区文件或 diff 中精准标记特定代码行，并将这些批注转化为给 Agent 的结构化指令。

当你希望先直观审查代码，再让 Agent 针对一系列明确的审查意见执行操作时，可以使用此功能。

常见用例：

- 让 Agent 修复你手动审查指出的多行代码
- 在查看 diff 时随手记录疑问，稍后统一发送
- 将一轮代码审查交接给同一工作区中的新会话
- 在本次发送时仅包含所需批注，将其余批注暂时从下一条提示词中分离

## 功能可用性

评审批注功能默认开启。如需关闭，可前往 **Settings → Features → File review comments** 进行切换。

该功能可在以下会话工作区界面中使用：

- 文件详情
- diff 详情
- Git 审查视图
- 发送批注后显示在会话记录中的评审批注卡片

评审批注具备工作区感知能力。其作用域严格限定在当前的服务器、设备和工作区文件夹内，因此某个项目的批注绝不会出现在另一个项目中。

## 添加评审批注

从 **Files** 或 **Git** 中打开文件或 diff，然后将鼠标悬停或聚焦到支持批注的代码行。

点击代码行旁边的交互入口即可打开输入框。无论点击行号槽（gutter）还是批注图标，交互效果完全一致。

保存批注时，Kaiwu 会记录以下信息：

- 相对于工作区的文件路径
- 批注来源于文件视图还是 diff 视图
- 当前可见的行号
- 选中代码行前后的简短代码片段
- 稳定的代码行内容哈希（可用时）
- 你填写的批注内容

系统后续会再次展示该代码片段，方便你在发送前确认批注所对应的上下文。

## 代码行定位锚点

评审批注并非仅依据行号定位。

Kaiwu 还会尽可能为选中行存储内容哈希。即使文件内容发生增删位移，Kaiwu 也能借助该哈希重新定位到对应的代码行。即便无法匹配到完全一致的内容，已保存的行号和代码片段仍可为 Agent 和界面提供可靠的兜底上下文。

因此，已发送的评审批注会同时包含：

- 易于人类阅读的代码行引用，例如 `L8`
- 代码行哈希（可用时），例如 `lh1:...`

## 编辑、删除、包含或分离批注

已保存的批注在发送或丢弃前始终保持可编辑状态。

你可以通过以下入口进行管理：

- 文件或 diff 内的代码行内联批注区
- 输入框中的 **Review** 标签
- 从该标签或附件角标弹出的评审批注管理窗口

在管理窗口中，你可以：

- 查看上下文代码片段
- 编辑批注内容
- 删除批注
- 选择将哪些批注包含在下一条提示词中

关闭或移除输入框中的标签并不一定会删除批注。Kaiwu 会询问你的意图：

- 仅从下一条提示词中分离
- 直接丢弃已保存的批注

已分离的批注仍会保留在工作区中，但不会随下一条消息发出。

## 在现有会话中发送评审批注

当工作区中存在已保存的评审批注时，会话输入框会显示 **Review** 标签以及评审附件角标。

发送之前，点击该标签可检查即将发送的内容，支持单独勾选或取消勾选各项批注。

发送时，Kaiwu 会将选中的批注转化为结构化评审上下文。Agent 将接收到：

- 各文件的相对路径
- 代码行锚点
- 代码行哈希（可用时）
- 上下文代码片段
- 你的批注内容
- 你在输入框中填写的附加提示词

发送成功后，已发送的批注会作为评审批注卡片转入会话记录。未被勾选的批注仍会继续保存在当前工作区中。

## 携带已保存的评审批注开启新会话

评审批注的作用域归属于工作区，而非局限于单一会话。

只要在相同的服务器、设备和工作区文件夹下创建新会话，Kaiwu 就能识别出已保存的批注，并在新会话的输入框中展示 **Review** 标签。

无论所选文件夹是显示为绝对路径，还是显示为类似 `~/Documents/project` 的家目录相对路径，只要两者最终指向同一工作区，该机制均能正常生效。

适用场景：

- 在某个会话中收集审查意见，随后开启一个全新的干净会话进行跟进
- 调用不同的提供商或配置文件来处理这批审查意见
- 将代码审查与实际开发实现拆分到不同会话中处理

## 会话记录中的评审批注

批注发送后，会话记录会将其渲染为结构化的评审批注卡片。

卡片会按文件对批注进行归类，并展示：

- 相对于工作区的文件路径
- 锚点标签
- 相关的代码片段
- 批注内容
- **Jump** 操作按钮

点击 **Jump** 可以在会话工作区界面中直达引用的文件或 diff。在桌面端上，这会展开右侧边栏/详情面板；在小屏幕设备上，则会打开全屏详情页。

## 搭配附件与链接文件使用

评审批注可以与普通提示词文本及消息附件组合发送。

建议根据不同场景选用合适的上下文工具：

- **Review comments**（评审批注）：绑定到工作区文件或 diff 特定行的具体指令
- **Link file**（链接文件）：直接引用工作区中的现有文件，无需针对特定代码行撰写批注
- **Attachments**（附件）：上传外部文件，例如截图、PDF、日志或导出的生成文件

## 使用限制

- 评审批注依赖设备提供的工作区文件或 diff 数据。
- 批注的作用域严格限定于特定的服务器、设备和工作区路径。
- 如果底层文件变动剧烈，Kaiwu 可能无法借助哈希重新定位到确切行，但记录的原始行号与代码片段依然可用。
- 路由团队成员消息目前不支持携带评审批注草稿。如需发送评审批注，请改用常规的主导消息。
