title: 桌面应用 (Tauri)
description: 基于 Web UI 的可选原生桌面封装。
---
Tauri 应用是对 Web 界面的原生桌面封装。适合以下使用场景：

- 需要原生桌面窗口（而非浏览器标签页）
- 存储与其他桌面安装相互隔离（避免复用旧的服务端 URL 或认证凭据）

## 关键行为

- Tauri 应用必须内嵌明确的 API 基础 URL。
- 默认情况下，`hstack` 会内嵌以下内容：
  - 若在当前设备上检测到 **Tailscale Serve**，则内嵌 `https://*.ts.net` URL（这样构建出的应用可直接分发给同一 tailnet 上的其他设备使用）；
  - 否则内嵌本地回环 URL `http://127.0.0.1:⟦K4⟧`（仅限当前设备访问）。
- 如需更改内嵌的 URL，请重新构建 Tauri 应用。

## 前置条件

- 已安装 Rust 工具链
- 已安装适用于当前操作系统的 Tauri 构建依赖

## 构建应用

单次构建：

```bash
hstack build --tauri
```

或在引导初始化时构建：

```bash
hstack bootstrap --tauri
```

## 运行应用

1) 启动本地服务端（或安装系统服务）：

```bash
hstack start
```

2) 启动构建出的应用包（位于 `~/.happier/stacks/main/tauri-target/` 目录下）。

## “便携式”Tauri 构建产物（分发至其他电脑）

如果在服务端设备启用 Tailscale Serve 期间构建 Tauri 应用，该应用将内嵌 `https://*.ts.net` URL，可直接拷贝至其他电脑运行。

前置要求：

- 服务端设备正在运行 `hstack start` 且已启用 Tailscale Serve
- 目标电脑处于同一 tailnet 内，且能够访问 `https://*.ts.net` URL

## 关键配置项

- `HAPPIER_STACK_TAURI_IDENTIFIER`（默认 `com.happier.stack`）
- `HAPPIER_STACK_TAURI_PRODUCT_NAME`（默认 `Kaiwu`）
- `HAPPIER_STACK_TAURI_DEBUG=0`（以类似 Release 的模式构建，不包含 DevTools）
- `HAPPIER_STACK_TAURI_SERVER_URL`（强制指定内嵌的 API URL）
- `HAPPIER_STACK_TAURI_PREFER_TAILSCALE=0`（禁用 Tailscale 检测；始终内嵌 `127.0.0.1`）
