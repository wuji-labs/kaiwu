本文档介绍 `hstack remote daemon setup`，这是一套通过 SSH 配置**远端设备**（如 VPS、家庭服务器、开发机）的工作流：

- 在远端主机上安装 Kaiwu CLI
- 将远端主机与你的账号完成配对并认证
- （可选）以**用户服务**形式安装并启动守护进程

## 快速开始

在已完成 Kaiwu 认证的设备上执行：

```bash
hstack remote daemon setup --ssh user@host
```

默认行为：

- 使用 **stable** 通道（如需获取更新的公开发布版本，请设置 `--channel preview` 或 `--channel dev`）
- 以 **user** 模式安装并启动守护进程服务

## 发布通道

```bash
hstack remote daemon setup --ssh user@host --channel preview
```

```bash
hstack remote daemon setup --ssh user@host --channel dev
```

等效简写形式：

```bash
hstack remote daemon setup --ssh user@host --preview
hstack remote daemon setup --ssh user@host --dev
hstack remote daemon setup --ssh user@host --stable
```

## 指定自托管服务器

如果要将远端设备配对到自托管服务器，请传入对应 URL，以便本地审批步骤正确定位控制平面：

```bash
hstack remote daemon setup --ssh user@host \
  --server-url https://api.example.com \
  --webapp-url https://app.example.com \
  --public-server-url https://api.example.com
```

说明：

- `--server-url` 为服务器 API 根地址。
- `--webapp-url` 为用于登录/审批交互界面的 Web UI 来源地址。
- `--public-server-url` 为其他设备可访问的服务器 URL（通常与 `--server-url` 相同）。

## 跳过守护进程服务安装

如果只需安装 CLI 并完成认证（无需保持守护进程常驻）：

```bash
hstack remote daemon setup --ssh user@host --service none
```

## 底层封装机制（配对细节）

在底层，`hstack remote daemon setup` 编排的配对流程与以下文档介绍的一致：

- [配对 JSON（手动 / 脚本）](/apps/cli#配对json手动--脚本)
- [通过 SSH 进行远端设备配对（自动化）](/apps/cli#远程设备配对ssh自动化)

如果需要，你也可以直接使用 Kaiwu CLI 执行配对：

```bash
happier auth pair-remote --ssh user@host --json
```

## 前置要求

- 具备远端主机的 SSH 访问权限（`ssh user@host`）
- 远端主机已安装 `bash` 和 `curl`
- 远端主机必须为类 Unix 系统（Linux/macOS）。此 SSH 工作流不支持 Windows 主机。
