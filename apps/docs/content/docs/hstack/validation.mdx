---
title: 验证（类型检查、代码检查、测试）
description: 在当前检出或栈范围内运行检查（推荐）。
---
大多数 hstack 命令都支持 `--help` 与 `--json`。

---

## 验证当前检出（非栈）

```bash
hstack typecheck all
hstack lint all
hstack test all
```

针对特定区域：

```bash
hstack typecheck ui
hstack typecheck cli
hstack typecheck server
```

---

## 在栈内验证（推荐）

栈作用域下的验证会应用对应栈的环境配置（端口、服务器 URL、数据库配置、CLI 主目录等）。

```bash
hstack stack typecheck exp1 all
hstack stack lint exp1 all
hstack stack test exp1 all
```

针对特定区域：

```bash
hstack stack typecheck exp1 ui
hstack stack lint exp1 cli
hstack stack test exp1 server
```

---

## 面向 CI 的检查

hstack 还提供了 `ci` 命令，用于执行标准化运行：

```bash
hstack ci --help
```

当你需要执行可复现的“策略规范”运行（并与维护者的运行标准保持一致）时，可以使用此命令。
