本文档介绍 `hstack remote server setup`，该工作流用于通过 SSH 配置**远程设备**（如 VPS、家庭服务器、开发机）：

- 在远程主机上安装 `hstack` 工具链（通过标准安装程序）
- 运行现有的引导式安装程序：`hstack self-host install`
- 将服务端运行时安装为托管服务（默认：**user** 模式）

如果你希望为 **CLI + 守护进程**场景配置远程设备（包含配对/身份验证），请参阅：[远程守护进程配置 (SSH)](/hstack/remote-daemon)。

## 快速上手

```bash
hstack remote server setup --ssh user@host
```

默认行为：

- 使用 **stable** 通道（如需更新的公开发布版本，请设置 `--channel preview` 或 `--channel dev`）
- 以 **user** 模式安装自托管服务
- 使用自托管默认配置（SQLite、本地文件、`PORT=3005`）

## 发布通道

```bash
hstack remote server setup --ssh user@host --channel preview
```

```bash
hstack remote server setup --ssh user@host --channel dev
```

等效快捷方式：

```bash
hstack remote server setup --ssh user@host --preview
hstack remote server setup --ssh user@host --dev
hstack remote server setup --ssh user@host --stable
```

## 用户服务与系统服务

用户服务（默认）：

```bash
hstack remote server setup --ssh user@host --mode user
```

系统服务：

```bash
hstack remote server setup --ssh user@host --mode system
```

说明：

- `--mode system` 会使用 `sudo -E` 执行远程安装，根据主机的 sudo 策略，可能需要提示输入密码。
- 除非明确需要系统级服务语义，否则推荐使用用户模式。

## 覆盖服务端配置（环境变量）

你可以多次传入 `--env KEY=VALUE` 参数。这些参数会覆盖远程主机上生成的 `server.env` 配置。

示例：更改监听端口：

```bash
hstack remote server setup --ssh user@host \
  --env PORT=3999
```

示例：使用 Postgres 代替 SQLite：

```bash
hstack remote server setup --ssh user@host \
  --env HAPPIER_DB_PROVIDER=postgres \
  --env DATABASE_URL=postgresql://user:pass@db:5432/happier
```

提示：有关服务端环境变量的完整配置项，请参阅[环境变量](/self-hosting/env)。

## 自动更新调度（每日时间窗口）

自动更新为可选功能。远程服务端配置默认不会设置计划任务。

完成配置后，可以通过运行以下命令来设置远程主机的更新时间窗口：

```bash
ssh user@host "~/.happier/bin/hstack self-host config set --auto-update --auto-update-at=03:15"
```

## 环境要求

- 具备对远程主机的 SSH 访问权限（`ssh user@host`）
- 远程主机已安装 `bash` 和 `curl`
- 远程主机必须是类 Unix 操作系统（Linux/macOS）。该 SSH 配置流程不支持 Windows 主机。
