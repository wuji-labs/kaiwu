`hstack` 用于直接从本地代码仓库运行 Kaiwu。它的核心职责是实现隔离：在同一台设备上并行运行多套完整的实例（**栈**），每个栈各自绑定独立的代码检出、端口和数据目录，避免正在测试的分支干扰日常开发分支。

进行交互式操作时，推荐使用 TUI 包装器。它可以实时展示各条命令的执行动态，无需自行翻阅日志文件：

```bash
hstack tui stack dev dev
```

## 隔离机制原理

以下四篇文档介绍了隔离机制的核心模型。若遇到两个栈意外共享资源的情况，请先参阅这些内容：

- [栈](/hstack/stacks) —— 隔离实例：端口、目录与代码仓库绑定机制。
- [工作树与 Fork](/hstack/worktrees-and-forks) —— 保持上游 PR 工作树干净整洁，隔离 fork 专属补丁。
- [认证（dev-auth 预置）](/hstack/auth) —— 一次性预置凭据，新栈随取随用，无需重复登录。
- [服务端版本类型](/hstack/server-flavors) —— 轻量版（基于 SQLite，可选 PGlite）与完整版（由 Docker 托管的基础设施）。
