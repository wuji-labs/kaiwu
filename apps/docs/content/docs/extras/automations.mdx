有些工作适合定时自动执行，而不是想起来才去做：比如每晚检查依赖、周一早晨分类 issue，或是定期对关注的代码仓库运行提示词。借助自动化功能，无需打开应用，这些任务就能在你的设备上自动运行。

<Callout type="warn">
  自动化功能目前处于实验阶段。未开启时，应用内的提示明确说明了启用方式：前往 Settings，然后开启 **Experiments** 与 **Automations**。实验性功能总开关控制着该选项，因此两者都需开启。
</Callout>

前往 **Settings → Automations** 即可找到该功能——“管理定时会话与周期运行任务”。

## 两种类型

**定时会话（scheduled session）**会按照预设时间表，在你指定的设备上启动新会话。这种类型适用于无需人工值守的任务：可在新建会话流程中直接创建，彼时你已选好设备、目录、agent 与模型。

**会话自动化（session automation）**则会定期向已有会话中排入消息。如果你希望在长期保留的对话中定期触发提示，可在该会话内直接添加。

## 调度设置

计划任务支持时间间隔（每 *n* 分钟）或 Cron 表达式，并提供了常用预设（**Every hour**、**Daily midnight**）。Cron 计划会基于你设置的时区运行，因此“每天午夜”是指你所在时区的午夜，而非设备本地所认定的午夜时间。

每项自动化都处于 **Active** 或 **Paused** 状态。暂停会保留配置并停止执行，适合离开或休假时使用。

## 立即运行

**Run now** 可以立刻触发自动化，无需等待下一次计划时间——便于在脱手运行前验证新建的自动化是否符合预期。

任务采用队列机制而非同步执行：指定的守护进程就绪后会自动拾取任务。若设备处于休眠状态，任务会等待唤醒，而不会直接报错。

在终端中执行：

```bash
happier automation run <automation-id> [--idempotency-key <key>] [--json]
```

若调用方可能重试，请传入 `--idempotency-key`——重复的 key 不会触发二次运行。
