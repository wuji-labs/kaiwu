本文汇总了无极开物（Kaiwu）当前面向用户呈现的核心功能。

状态说明：

- **稳定**：适合日常使用
- **实验性**：已提供，仍在持续打磨
- **能力依赖**：取决于后端或提供商的能力支持

## 核心功能

| 功能 | 状态 | 适用端 | 说明 |
| --- | --- | --- | --- |
| 多服务器配置与切换 | 稳定 | 客户端、Web、CLI | 账号与运行时状态均按服务器隔离。 |
| 会话分享与协作 | 稳定 | 客户端、Web | 与好友或团队成员分享会话，并管理访问权限。 |
| 会话已读/未读状态 | 稳定 | 客户端、Web、移动端 | 会话列表、右键菜单、顶栏及“会话信息”中均提供未读徽标与“标为未读/已读”操作。 |
| Kaiwu 会话与恢复 | 稳定 | 客户端、Web、CLI | 当提供商或后端支持恢复该会话时，可恢复非活跃的 Kaiwu 托管会话。 |
| 新建会话快捷方式 | 稳定 | 客户端、Web、移动端 | 从项目或“会话信息”发起新会话，同时复用原会话的相关配置；启动参数会按新选择替换，输入框中已有的草稿内容则予以保留。 |
| 跨设备会话交接 | 能力依赖 | 客户端、Web | 在保持会话 ID 不变的情况下，将正在进行的会话迁移到另一台设备。已支持 Claude 和 OpenCode；Codex 处于实验性阶段。 |
| 直连提供商原生会话 | 实验性 | 客户端、Web | 浏览提供商原生会话，直接打开，并可选择将其同步至 Kaiwu。 |
| 移动端会话控制台 | 稳定 | 移动端、移动端 Web | 手机端的默认会话布局，底部标签栏集成智能体对话、文件、Git、已打开的详情标签页，以及终端（可用时）。 |
| 内嵌终端 | 实验性 | 客户端、Web、移动端 | 隶属于会话的终端，可吸附固定在底部、侧边栏或详情区；需要已连接的守护进程且设备网络可达。 |
| 待发送队列 | 稳定 | 客户端、Web、CLI 运行时 | 支持加入队列、重新排序、编辑、移除以及立即发送等操作流。 |
| 繁忙时动态介入调整 | 能力依赖 | 客户端、Web、CLI 运行时 | 当后端或运行时支持时，新消息可直接干预正在进行的轮次，无需在队列中等待。 |
| Git 与文件管理器 | 稳定 | 客户端、Web、移动端 | 直接在会话界面中浏览/搜索文件、上传/下载、重命名/删除、打开预览/编辑器、查看元数据、打开 Markdown 文件链接、初始化 Git 仓库以及审查变更文件。 |
| Git 写入操作 | 实验性 | 客户端、Web、移动端 | 受 Git 操作特性开关控制，支持暂存/取消暂存/提交/拉取/推送/回退，以及挑选文件提交、分支发布/切换/暂存、分支检出恢复和自动生成提交信息等操作流。 |
| 按轮次/会话/选中范围查看变更文件 | 能力依赖 | 客户端、Web、移动端 | 在数据可用时，Git 变更文件范围下拉菜单可展示整个仓库的变更、最新一轮的变更、当前会话产生的变更，以及选定准备提交的文件。 |
| 代码托管平台集成 | 实验性 | 客户端、Web、守护进程 | 自动识别 GitHub/GitLab/Bitbucket 远端仓库；在完成提供商认证的前提下，支持将本地仓库发布到 GitHub，以及打开、复用或检出 PR/MR。 |
| 审查评论 | 实验性 | 客户端、Web | 针对文件或 Diff 逐行添加评论，自主选择发送哪些评论；可在新会话中复用已保存的工作区评论，也能从会话记录快速跳转回被评论的文件。 |
| 工具时间线归一化 | 稳定 | 客户端、Web、CLI 运行时 | 将不同提供商的工具调用统一归一化为规范的 UI 工具类型。 |
| 子智能体时间线透出 | 能力依赖 | 客户端、Web | 当提供商暴露子智能体时，Kaiwu 会在会话内展示其活动。 |
| 工具详情粒度控制（标题/摘要/完整） | 稳定 | 客户端、Web | 支持配置时间线的默认展示粒度，也可按工具单独指定。 |
| 轮次级变更摘要 | 能力依赖 | 客户端、Web | 单轮摘要和 Diff 渲染效果取决于提供商或运行时返回的数据负载。 |
| 权限模式 | 能力依赖 | 客户端、Web、CLI | 实际生效行为取决于提供商或后端的能力支持。 |
| 模型/模式选择与收藏 | 能力依赖 | 客户端、Web、CLI | 模型列表支持动态或静态呈现；在新建会话的引擎选择器中可直接使用收藏夹。 |
| 已连接服务 | 稳定 | 客户端、Web、CLI、守护进程 | 只需一次性连接提供商订阅、API Key 和 GitHub Token，即可在受支持的后端、会话及版本控制流程中统一复用。 |
| 已连接服务认证选择器 | 稳定 | 客户端、Web | 新建会话时的认证选择器仅展示与当前后端兼容的已连接服务及配置。 |
| 已连接服务额度 | 能力依赖 | 客户端、Web、守护进程 | 目前已为 `openai-codex`、`claude-subscription` 和 `gemini` 提供配额徽标与详细配置计量仪表盘。 |
| 本地记忆搜索 | 实验性 | 客户端、Web、守护进程 | 可选开启的设备本地会话记录搜索，支持轻量/深度索引、历史数据补录控制，以及可选的 Embeddings 重排。 |
| 桌宠伙伴 | 实验性 | 客户端、Web、移动端、桌面端、守护进程 | 可选的桌宠伴侣功能；提供内置桌宠，支持 Codex 兼容导入、桌面悬浮气泡、移动端/原生端拖拽交互、按设备调整尺寸以及服务端特性开关控制。 |
| ACP 后端 | 实验性 | 客户端、Web、CLI 运行时 | 支持通过“自定义 ACP”添加任意兼容 ACP 的 CLI 工具，并将每个配置好的后端作为一等后端选项来使用。 |
| 可安装工具 | 稳定 | 客户端、Web、守护进程 | 管理设备本地工具（如 Codex ACP 和可选的 GitHub CLI（`gh`）），并支持按设备配置安装与更新策略。 |
| 服务端特性开关 | 稳定 | 客户端、Web、服务端 | 服务端可关闭特定功能（如社交、语音、错误报告等），各客户端会随之自适应调整界面。 |
| 通知路由至会话/服务器 | 稳定 | 客户端、Web | 点击通知可精准跳转至对应的会话与服务器；移动端还支持权限 `Allow` / `Deny` 以及操作请求 `Answer` 按钮，具备安全的服务端感知路由能力。 |
| 应用内错误报告与诊断 | 稳定 | 客户端 | 提交问题报告并可附带诊断信息；服务端可关闭上传与报告入口界面。 |
| 语音：Kaiwu Voice | 能力依赖 | 客户端、Web | 托管式实时 ElevenLabs 语音；需要服务端配置语音并开启对应功能。 |
| 语音：自备 ElevenLabs | 稳定 | 客户端、Web | 使用您自己的 ElevenLabs 账号或 API Key，支持声音试听预览，并可配置或更新兼容 Kaiwu 的 ElevenLabs 智能体。 |
| 语音：本地语音 | 实验性 | 客户端、Web | 自由组合设备内置、OpenAI 兼容、Google 以及本地神经网络 STT/TTS 提供商；支持直入会话和智能体对话两种模式。 |
| 语音：本地神经语音 | 实验性 | 客户端、Web | Kokoro 本地神经 TTS 同时支持 Web 和原生环境；Sherpa 本地神经 STT 当前仅支持原生构建版本。 |
