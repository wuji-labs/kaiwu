Kaiwu 支持接入基于本地 CLI 的 Qwen 提供商。

<Callout type="info">
  Qwen Code 属于**实验性**集成。该功能已可正常使用，且有用户在日常工作中依赖它；但与 Claude、Codex 或 OpenCode 相比，其接口面尚处早期阶段，后续更有可能发生调整。当前支持的功能请参阅[智能体能力](/agents/capabilities)。
</Callout>

## 环境要求

- 本地已安装 Qwen CLI。
- 可执行文件已添加至 `PATH`（或设置 `HAPPIER_QWEN_PATH`）。

## 安装 Qwen

Kaiwu 可以代你安装：

```bash
happier install provider qwen
qwen --version
```

也可以手动安装（macOS / Linux）：

```bash
curl -fsSL https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.sh | bash
qwen --version
```

Windows（在 CMD 中以管理员身份运行）：

```bat
curl -fsSL -o %TEMP%\\install-qwen.bat https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.bat && %TEMP%\\install-qwen.bat
qwen --version
```

## 在 Kaiwu 中进行本地认证

Qwen 支持从以下路径发起原生认证流程：

- **Settings → AI & Agents → AI backends → Qwen Code**

Kaiwu 会自动打开 Qwen 并代你发送 `/auth`。

目前对 Qwen 认证状态的检测较为保守，因此即便登录流程可用，Kaiwu 也仍可能显示为 **Unknown**。

通用说明请参阅[提供商认证](/agents/provider-authentication)。

## 在 Kaiwu 中启动 Qwen

```bash
happier qwen
```

## 注意事项

- 会话能否恢复取决于具体的会话，需要具备有效的恢复元数据，并结合当前的后端与设置判断。
- 模型、运行模式以及权限行为可能因安装的 Qwen 运行时版本不同而存在差异。
- 工具调用均已归一化，交由 Kaiwu 标准工具渲染器呈现。

## 故障排查

如果系统未能检测到 Qwen：

1. 验证 `qwen --version` 是否正常运行。
2. 重启 Kaiwu。
3. 如有需要，配置 `HAPPIER_QWEN_PATH`。
