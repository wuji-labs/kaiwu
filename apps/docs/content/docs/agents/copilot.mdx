Kaiwu 可以通过设备上的本地 `copilot` 二进制文件运行 **GitHub Copilot CLI**。

<Callout type="info">
  Copilot 目前属于**实验性**集成。该功能完全可用且已有日常使用，但相比 Claude、Codex 或 OpenCode，其接口更新，也更容易发生变动。目前支持的能力请参见 [Agent 能力](/agents/capabilities)。
</Callout>

## 前置要求

- 本地已安装 Copilot CLI
- 二进制文件位于 `PATH` 中（或已在 Kaiwu 的 CLI 路径设置中完成配置）

## 安装 Copilot

Kaiwu 支持自动安装：

```bash
happier install provider copilot
copilot --version
```

也可以手动安装：

```bash
npm install -g @github/copilot
copilot --version
```

## 在 Kaiwu 中进行本地认证

Kaiwu 会在此路径下显示 Copilot 在设备本地的认证状态：

- **设置 → AI 与 Agent → AI 后端 → Copilot**

在此页面中，你可以：

- 检查 Copilot 是否已在所选设备上完成认证
- 直接在 Kaiwu 内调起原生的 `copilot login` 流程
- 点击**立即检查**刷新认证状态

Kaiwu 目前会从以下途径检测 Copilot 认证状态：

- `COPILOT_GITHUB_TOKEN`
- `GH_TOKEN`
- `GITHUB_TOKEN`
- 本地 GitHub CLI 的认证状态（若可用）

通用用户指南请参见[提供商认证](/agents/provider-authentication)。

## 注意事项

- Kaiwu 中的 Copilot 认证仅针对当前设备生效。你在某台设备上登录后，其他设备仍需各自在本地完成登录。
- 如果你倾向于使用基于 Token 的认证，Kaiwu 也能自动检测，并显示为由环境变量支持的认证方式。

## 故障排查

若未检测到 Copilot：

1. 确认 `copilot --version` 可以正常运行。
2. 重启 Kaiwu。
3. 重新打开提供商设置页面，并点击**立即检查**。
