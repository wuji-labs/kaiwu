Kaiwu 支持通过本地 `pi` CLI 运行 **Pi Coding Agent**。

<Callout type="info">
  Pi 目前是一项**实验性**集成。它功能完备，且已有用户在日常使用，但其接入接口相比 Claude、Codex 或 OpenCode 更加初期，后续更可能发生变动。当前支持的功能详见 [Agent 功能特性](/agents/capabilities)。
</Callout>

## 安装 Pi

Kaiwu 可以代你自动安装：

```bash
happier install provider pi
pi --version
```

也可以手动安装：

```bash
npm install -g @earendil-works/pi-coding-agent
pi --version
```

## 在 Kaiwu 中启动 Pi

```bash
happier pi
```

## Kaiwu 本地认证

Pi 目前尚未通过 Kaiwu 的提供商设置提供原生交互式登录流程。

Kaiwu 会在以下路径展示当前设备上 Pi 的本地认证状态：

- **Settings → AI & Agents → AI backends → Pi**

目前，该状态取决于所选设备上受支持的环境变量凭据。

通用用户指南请参阅 [提供商认证](/agents/provider-authentication)。

## 认证（关联服务）

由 Kaiwu 启动时，Pi 可以复用关联服务的配置：

- `openai-codex`（订阅 OAuth）
- `openai`（API 密钥）
- `claude-subscription`（OAuth 或 setup-token），用于 Claude 订阅认证
- `anthropic`，用于 Anthropic API 密钥认证（`ANTHROPIC_API_KEY`）

启动前，Kaiwu 会将兼容的关联服务写入 Pi 隔离的 `PI_CODING_AGENT_DIR/auth.json` 中。Claude 订阅 OAuth 配置会转写为 Pi OAuth 凭据；setup-token 和 API 密钥配置则会转写为 Pi API 密钥凭据。

如果存在多个兼容的配置，Kaiwu 会在新建会话时由你选择其一。

合规说明：Claude 订阅 OAuth 凭据旨在供 Anthropic 原生应用中的常规 Claude 订阅使用。开发第三方产品的工程师应使用 Anthropic API 密钥或受支持的云提供商，除非其策略及法务审查明确允许采用该 Pi 集成方案。

参见：[关联服务](/accounts/connected-services)

## 故障排查

如果未检测到 Pi：

1. 确认 `pi --version` 可以正常运行。
2. 重启 Kaiwu。
3. 如果可执行文件不在 `PATH` 中，请配置 `HAPPIER_PI_PATH`。
