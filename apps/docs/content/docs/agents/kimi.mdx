Kaiwu 支持接入 Kimi 作为本地 CLI 提供商。

<Callout type="info">
  Kimi 属于**实验性**集成。该功能稳定可用且已有人在日常使用，但相比 Claude、Codex 或 OpenCode，它起步较晚，接口变动的可能性也更大。当前支持的功能详见[智能体功能支持](/agents/capabilities)。
</Callout>

## 环境要求

- 本地已安装 Kimi CLI。
- 二进制文件已加入 `PATH`（或设置 `HAPPIER_KIMI_PATH`）。

## 安装 Kimi

Kaiwu 可以代你运行官方安装程序：

```bash
happier install provider kimi
```

或者自行手动安装（macOS / Linux）：

```bash
curl -LsSf https://code.kimi.com/install.sh | bash
kimi --version
```

Windows (PowerShell)：

```powershell
Invoke-RestMethod https://code.kimi.com/install.ps1 | Invoke-Expression
kimi --version
```

## 在 Kaiwu 中进行本地认证

你可以通过以下路径启动 Kimi 原生的配置/登录流程：

- **Settings → AI & Agents → AI backends → Kimi**

Kaiwu 会启动 Kimi 并自动为你发送 `/setup`。

目前对 Kimi 认证状态的检测策略较为保守，因此即使登录流程可用，Kaiwu 仍可能显示为 **Unknown**。

通用用户指南请参阅[提供商认证](/agents/provider-authentication)。

## 在 Kaiwu 中启动 Kimi

```bash
happier kimi
```

## 注意事项

- Kaiwu 能否恢复会话因会话而异，取决于是否存在有效的恢复元数据以及当前的后端/配置。
- 模型、模式和权限的具体行为仍可能因所安装的 Kimi 运行时版本不同而有所差异。
- 工具调用均已归一化，接入 Kaiwu 规范的工具渲染器。

## 故障排查

如果未检测到 Kimi：

1. 验证 `kimi --version` 能否正常执行。
2. 重启 Kaiwu。
3. 必要时设置 `HAPPIER_KIMI_PATH`。
