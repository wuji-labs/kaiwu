Kaiwu 通过 **Auggie** 后端/运行时集成了 Augment。

<Callout type="info">
  Auggie 目前属于**实验性**集成。该功能完全可用且已有用户日常使用，但相较于 Claude、Codex 或 OpenCode，其接口更年轻，后续变动的可能性也更大。目前支持的功能详见 [Agent 功能特性](/agents/capabilities)。
</Callout>

## 运行环境要求

- 本地已安装 Auggie CLI。
- 可执行文件已包含在 `PATH` 中（或已设置 `HAPPIER_AUGGIE_PATH`）。

## 安装 Auggie

Kaiwu 可以为你自动安装：

```bash
happier install provider auggie
auggie --version
```

也可以手动安装：

```bash
npm install -g @augmentcode/auggie
auggie --version
```

## 在 Kaiwu 中进行本地认证

Auggie 支持通过以下路径发起原生登录流程：

- **设置 → AI 与 Agent → AI 后端 → Auggie**

在该页面中，你可以：

- 直接在 Kaiwu 内打开 `auggie login`
- 点击**立即检查**，在所选设备上重新运行认证检查

目前 Auggie 的认证状态检测策略偏保守。即便登录流程正常可用，Kaiwu 也仍可能显示为**未知**。

通用用户指南请参阅 [提供商认证](/agents/provider-authentication)。

## 在 Kaiwu 中启动 Augment/Auggie

```bash
happier auggie
```

## 注意事项

- 会话恢复（Resume）功能的可用性因会话而异，取决于是否存在有效的恢复元数据以及当前的后端/设置。
- 模式、权限和模型行为仍可能随安装的运行时版本而有所差异。
- 会话工具会规范化映射为标准的 Kaiwu 时间线工具。

## 故障排查

如果未检测到 Auggie：

1. 验证 `auggie --version` 是否能正常运行。
2. 重启 Kaiwu。
3. 必要时设置 `HAPPIER_AUGGIE_PATH`。
