Kaiwu integrates Augment using the **Auggie** backend/runtime.

<Callout type="info">
  Auggie is an **experimental** integration. It works and people use it
  daily, but its surface is younger than Claude, Codex or OpenCode and is
  more likely to change. What it supports today is in
  [Agent capabilities](/agents/capabilities).
</Callout>

## Requirements

- Auggie CLI installed locally.
- Binary available on `PATH` (or set `HAPPIER_AUGGIE_PATH`).

## Install Auggie

Kaiwu can install it for you:

```bash
happier install provider auggie
auggie --version
```

Or install manually:

```bash
npm install -g @augmentcode/auggie
auggie --version
```

## Local authentication in Kaiwu

Auggie supports launching its native login flow from:

- **Settings → AI & Agents → AI backends → Auggie**

Use that page to:

- open `auggie login` directly inside Kaiwu
- re-run auth checks on the selected machine with **Check now**

Auth-status detection for Auggie is currently conservative. Kaiwu may still show **Unknown** even though the login flow is available.

For the shared user guide, see [Provider authentication](/agents/provider-authentication).

## Start Augment/Auggie with Kaiwu

```bash
happier auggie
```

## Notes

- Resume availability is session-specific in Kaiwu and depends on valid resume metadata plus the current backend/settings.
- Modes, permissions, and model behavior can still vary by the installed runtime.
- Session tools are normalized into canonical Kaiwu timeline tools.

## Troubleshooting

If Auggie is not detected:

1. Verify `auggie --version` works.
2. Restart Kaiwu.
3. Set `HAPPIER_AUGGIE_PATH` if needed.
