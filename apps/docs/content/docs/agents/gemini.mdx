Kaiwu 通过本地 Gemini CLI/运行时以及兼容 ACP 的消息机制集成 Gemini。

<Callout type="info">
  Gemini 属于**实验性**集成。它功能完备，已有不少用户日常使用；但相比 Claude、Codex 或 OpenCode，它的接口面更年轻，后续变更的可能性也更高。目前支持的功能详见 [Agent 能力](/agents/capabilities)。
</Callout>

## 环境要求

- 设备上已安装 Gemini CLI。
- CLI 可在 `PATH` 中找到（必要时可设置 `HAPPIER_GEMINI_PATH`）。

## 安装 Gemini

Kaiwu 可自动为你安装：

```bash
happier install provider gemini
gemini --version
```

也可以手动安装：

```bash
npm install -g @google/gemini-cli
gemini --version
```

## 在 Kaiwu 中进行本地认证

Gemini 支持在设备本地管理认证，路径如下：

- **设置 → AI & Agents → AI 后端 → Gemini**

在此处你可以：

- 查看所选设备上 Gemini 的本地认证状态
- 直接在 Kaiwu 内唤起 Gemini 原生 CLI 的认证流程
- 点击**立即检查**刷新认证状态

Kaiwu 可以自动检测环境变量、本地 Gemini 认证/配置文件以及受支持的 Google ADC 文件中的 Gemini 认证信息。

通用使用指南详见[提供商认证](/agents/provider-authentication)。

## 在 Kaiwu 中启动 Gemini

```bash
happier gemini
```

## 认证（关联服务）

Gemini 认证通过 Kaiwu 关联服务（`gemini`）进行管理：

- 设置 → 关联服务 → Gemini
- 或通过 CLI：`happier connect gemini`

对于粘贴/重定向流程，Kaiwu 会在服务端换取 OAuth 代码，并将加密数据包返回给客户端（应用 UI 中不包含任何 Gemini OAuth 密钥）。

支持的 UI 交互方式：

- 粘贴重定向 URL
- 原生端内置应用内浏览器

在 Web 端，Kaiwu 采用粘贴流程。

如果你正在使用自托管服务且需要覆盖 OAuth 客户端配置，请参阅：

- [关联服务](/accounts/connected-services)

## 模型选择

模型选择基于能力驱动，支持通过以下方式设置：

- CLI 启动选项
- 应用内的会话输入设置（若当前运行时已开放支持）

跨提供商模型行为、实时模型列表及收藏设置，请参阅[模型与引擎选择](/agents/model-and-engine-selection)。

## 故障排查

- 若未检测到 Gemini，请确认 CLI 是否正确安装并重启 Kaiwu。
- 必要时，可使用 `HAPPIER_GEMINI_PATH` 显式指定二进制文件路径。
