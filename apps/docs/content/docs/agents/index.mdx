Kaiwu 并不会取代你现有的编程 Agent。它直接运行你常用的 Agent——就在你自己的设备上、你检出的代码库里——并让你无论身在何处，都能随时查看其进度、把控方向、审批操作并与之交流。

目前已接入 14 种 Agent。无论你选择哪一款，Kaiwu 原生支持的功能逻辑均完全一致：会话记录、待处理队列、权限与审批、会话设置、通知，以及 Agent 可调用的工具。不同之处仅在于各 Agent 自身的 CLI 所开放的能力——例如支持哪些模型、是否支持恢复会话，以及能否接收图片等。

## 运行 Agent

每个 Agent 的专属页面都涵盖相同的三项内容：安装其 CLI、完成身份验证，以及切实影响使用体验的限制条件。页面结构特意保持统一，以便你在不同的 Agent 之间无缝切换。

以下两点对所有 Agent 均适用：

- **需自行安装 Agent 的 CLI。** Kaiwu 只会检测当前设备上已有的组件，本身不内置任何 Agent。对于部分 Agent，Kaiwu 能够代为执行托管安装，具体支持情况请参见各功能对比表。
- **身份验证由 Agent 自行管理。** Kaiwu 会读取其登录状态；针对部分 Agent，Kaiwu 还可通过[已连接服务](/accounts/connected-services)为你保存凭据，免去在每台设备上分别登录的繁琐操作。

## 其他支持 ACP 的工具

针对未包含在上述列表中的 CLI，Kaiwu 提供了通用的 **Custom ACP** 类别。只需定义一次可供选择的 ACP 后端，它们就会作为标准 Agent 选项出现在 App 的各个位置——包括新建会话选择器、会话设置等所有场景。
