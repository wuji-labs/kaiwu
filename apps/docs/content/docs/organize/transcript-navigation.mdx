---
title: 浏览会话记录
description: 在轮次间跳转，置顶重要消息，并可选择消息复制或发送至另一个会话。
---
长会话往往难以翻阅。为了找到当初改变想法的那一轮对话，不得不向上滚动翻看一整天的工作记录——正是这种繁琐让很多人索性选择直接新建会话。为了解决这一痛点，Kaiwu 为会话记录引入了两大功能：用于快速跳转的导航界面，以及用于将消息转存至别处的选择模式。

## 导航界面

**导航**会列出会话中的所有轮次，方便你直接跳转到指定轮次。它提供两种模式：

- **全部**——列出用户的每一轮发言，无需反复滚动，即可回溯整个对话中的决策节点。
- **已固定**——仅显示已固定的消息，让长会话自带关键内容的专属索引。

即使目标内容尚未加载，跳转功能也能正常生效：Kaiwu 会先抓取该消息前后的历史记录，直到消息真正出现在屏幕指定位置后，才会反馈跳转成功。绝不会出现“提示已到达但屏幕上看不到”的情况。

导航界面的展现形态取决于可用空间的大小。在宽屏浏览器中，它是位于会话记录旁的悬浮导轨；在较窄的布局下，它会收拢为面板或浮层；在桌面端，它是右侧面板中的一个标签页；在手机端，它则是 [Cockpit](/apps/app) 的界面之一。

## 固定消息

将鼠标悬停在消息上，点击图钉图标即可。用户发言、助手回复以及符合条件的工具消息均支持固定。

<Callout type="info">
  **固定状态仅保存在当前设备上。** 它们不会同步到服务器，也不会跟随到其他设备。这种设计是经过深思熟虑的：固定功能只是一种阅读辅助手段，如果同步，就意味着要向服务器持久化发送指向特定消息的指针。
</Callout>

## 选择消息

点击一条消息即可开始选择，随后可追加勾选更多消息。选定消息后，你可以复制它们，或是将它们发送至其他会话。

**复制**默认采用带角色标签的 Markdown 格式，粘贴到别处时依然能分清是谁说的话。如果不希望这些标签干扰后续操作，也可以选择纯文本格式。

**发送到会话**会将选中的内容追加到目标会话的草稿中，而不会立即发出。切换过去后，这些内容已填入输入框，你可以先补充一两句背景说明再行发送。即便离开当前页面后再返回，草稿内容也不会丢失。

### 自定义发送格式

最终填入的内容遵循可自定义的模板，因此在转发时不仅能引用原文，还能一并附带操作说明。系统提供了三个占位符：

| 占位符 | 替换为 |
| --- | --- |
| `{{MESSAGES}}` | 所选消息本身 |
| `{{SELECTED_COUNT}}` | 所选消息的数量 |
| `{{SOURCE_SESSION_NAME}}` | 消息来源会话 |

如果不包含 `{{MESSAGES}}`，模板虽然可以保存，但系统会给出警告，因为这意味着选中的内容将无处安放。

## 开启相关功能

消息选择和转发功能可在 **设置 → 会话记录 → 消息操作** 中进行配置。在此处，你可以开启消息选择功能、开启“发送到会话”、选择复制格式以及编辑模板。
