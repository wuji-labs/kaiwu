title: API 速率限制
description: 所有受速率限制的端点、其默认值、计入的统计维度，以及用于修改该限制的两个环境变量。
---
Kaiwu 对其访问最频繁的端点设置了速率限制。默认配置适用于常规部署；通常只有在实际负载下观察到特定端点受限时才需要调高阈值，或者在面向公网的服务器上将其调低。

每个端点都对应两个环境变量：最大请求数和时间窗口。配置时需同时设置或均保持默认；如果仅设置最大请求数，时间窗口仍会沿用默认值，这通常并不符合预期。

时间窗口支持与默认值相同格式的时长字符串（`1 minute`、`30 seconds`、`1 hour`）。

相比具体数值，**限流的统计维度**更为重要。`Account` 限流按已登录账号生效，单一高频用户不会耗尽其他用户的配额。`IP address` 限流则在 Kaiwu 识别调用方身份之前生效，用于保护免认证路由；如果部署在反向代理之后，其准确度取决于代理所传递的客户端转发地址。全部 33 项限流中有 27 项均按账号统计。

在正式推行前，有两组限流值得特别关注，因为集中接入新用户时极易触发限流：`auth.pairing.*` 涵盖连接新设备，`connectedServices.deviceAuth.*` 涵盖从无头设备关联 Agent 账号。
