本节面向 Kaiwu 的**开发人员**，而非普通使用者。如果你是为了使用 Kaiwu，请前往[从这里开始](/getting-started)。

Kaiwu 在单个代码库中划分为多个工作区运作，包含客户端、CLI 与守护进程、中继，以及各组件间的共享契约包。大多数改动都会波及多个模块，这正是本地栈的用武之地：它基于你本地检出的代码运行整套系统，便于你端到端地验证改动效果。
