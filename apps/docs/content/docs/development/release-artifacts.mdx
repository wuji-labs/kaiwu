## 通道

- `stable`
- `preview`
- `dev`

## 制品命名

- CLI 二进制归档：`happier-v{version}-{os}-{arch}.tar.gz`
- hstack 二进制归档：`hstack-v{version}-{os}-{arch}.tar.gz`
- 自托管服务端运行时归档：`happier-server-v{version}-{os}-{arch}.tar.gz`
- 自托管 Web UI 资源包归档：`happier-ui-web-v{version}-web-any.tar.gz`
- 校验和：`checksums-{product}-v{version}.txt`
- 校验和签名：`checksums-{product}-v{version}.txt.minisig`

## 支持的目标平台

CLI + hstack：

- `linux-x64`
- `linux-arm64`
- `darwin-x64`
- `darwin-arm64`
- `windows-x64`

自托管服务端运行时：

- `linux-x64`
- `linux-arm64`
- `darwin-x64`
- `darwin-arm64`
- `windows-x64`

自托管 Web UI 资源包：

- `web-any`

## 清单结构（`/v1`）

每个平台清单均包含：

- `product`
- `channel`
- `version`
- `os`
- `arch`
- `url`
- `sha256`
- `signature`
- `publishedAt`
- `minSupportedVersion`
- `rolloutPercent`
- `critical`
- `notesUrl`
- `build.commitSha`
- `build.workflowRunId`

## 回滚策略

- CLI/hstack：滚动标签（`cli-stable` / `cli-preview` / `cli-dev`，`stack-stable` / `stack-preview` / `stack-dev`）与版本标签。
- 自托管运行时：服务端滚动发布标签与带版本的制品。
- 自托管 Web UI 资源包：Web UI 滚动发布标签与带版本的制品。
- `happier self update --to ⟦K1⟧` 为指定版本回滚的入口点。
